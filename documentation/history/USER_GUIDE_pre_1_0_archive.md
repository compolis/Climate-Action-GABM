# USER_GUIDE pre-1.0 archive

This document preserves where pre-1.0 version-specific user guidance now lives.
As of 2026-11-17, [USER_GUIDE.md](../../USER_GUIDE.md) is intentionally
current-version-only.

## Why this archive exists

Before 1.0, the project does not aim to support historical runtime paths for
regular users. Older guidance remains useful for historical context and
reproducibility, but it should not be treated as the recommended run path.

## Archived topics from prior USER_GUIDE revisions

The following topics were removed from the main user guide and archived:

- v0.8 configuration path (`memory` presets and prompt-assembly controls)
- v0.7 configuration path (CLI composition flags, checkpointing defaults, run-bundle expansion, connectivity safeguards)
- v0.6 configuration path (political exposure controls and affinity-target presets)
